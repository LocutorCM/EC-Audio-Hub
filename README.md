# EC Audio Projects

This repository contains EC Audio applications.

## EC Audio Hub for macOS
A native SwiftUI plugin library and downloader targeting macOS 12 Monterey and later, with Intel and Apple Silicon builds.

See [macOS/README.md](macOS/README.md) for features and build instructions. The macOS GitHub Actions workflow creates a universal app ZIP artifact.

## Android camera application
The existing Android project remains in the app/ directory. Its build workflow is separate from the macOS Hub.
