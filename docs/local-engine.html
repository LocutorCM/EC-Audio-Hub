EC AUDIO / LOCAL AI ENGINE

Instala el motor local

La página EC Audio se conecta a este motor que se ejecuta en tu computadora. No usa Hugging Face Spaces, Render ni un servicio de generación remoto.

macOS

Descarga y ejecuta el instalador. Si macOS lo bloquea, haz clic derecho sobre el archivo y selecciona Abrir. Necesitas Git y Xcode Command Line Tools; el instalador te indicará si falta algo.

DESCARGAR INSTALADOR MACOS

Windows

Ejecuta el instalador desde PowerShell. Necesitas Git for Windows y controladores actualizados de tu GPU.

DESCARGAR INSTALADOR WINDOWS

Requisitos y primera ejecución

  • La descarga de dependencias y modelos puede ocupar aproximadamente 10 GB o más.
  • ACE-Step indica un mínimo de 4 GB de VRAM para el modo básico; con menos memoria puede ser necesario usar CPU y el rendimiento será mucho más lento.
  • La primera carga puede tardar varios minutos. Mantén abierta la ventana de terminal para que el motor siga activo.
  • El sitio web se comunica únicamente con 127.0.0.1:8001, en tu propia computadora.

Cómo usarlo

  1. Ejecuta el instalador y espera a que el servidor indique que está listo.
  2. Abre EC AI Instrumental.
  3. Presiona «Comprobar conexión» y crea tu instrumental.
  4. Para cerrar el motor, vuelve a la terminal y presiona Ctrl+C.
